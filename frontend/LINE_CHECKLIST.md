# LINE 內建瀏覽器實機檢查清單

在真機上測：iOS（Safari 核心 WKWebView）與 Android（Chrome WebView）各跑一次。
測試前：開一個有 5 人以上名單、含「售完」品項與店家電話的團，取得訂購連結 `/g/<token>`。

## 分享與開啟
- [ ] 用「分享到 LINE」把連結貼到群組，預覽卡片顯示標題、說明、圖片（OG；若沒出現，先在 LINE 貼一次舊連結以外的新連結，快取需時）
- [ ] 點群組裡的連結，在 LINE 內建瀏覽器正常載入（無白屏、無無限轉圈）
- [ ] 「複製連結」成功並出現 toast；若無法自動複製，連結被選取、可長按複製
- [ ] 「開啟訂購頁」「分享到 LINE」按鈕可點、能跳出分享畫面

## 版面與安全區域
- [ ] 頂端 toast 不蓋住標題列（管理頁）；訂購頁 toast 不被底部按鈕列遮住
- [ ] 底部 sticky 按鈕列貼齊螢幕底，iPhone 有 Home 指示條時按鈕不被遮、下方有留白
- [ ] 捲到最底，「為核對訂單，系統會記錄 IP 與裝置資訊」完整可見，沒被按鈕列蓋住
- [ ] 橫向/縮放不產生水平捲軸

## 輸入
- [ ] 搜尋名字：用注音/拼音/手寫輸入組字中（底線狀態）篩選不會中斷或清空，選字後結果正確
- [ ] 所有輸入框點擊後頁面不會自動放大（字級 ≥ 16 px）
- [ ] 點搜尋框/備註叫出鍵盤：sticky 按鈕列不遮住正在輸入的欄位，欄位可捲到可見；收鍵盤後版面還原
- [ ] 品項 ＋/－ 按鈕連點不誤觸、不縮放，數量即時更新，總額正確
- [ ] 「＋備註」展開輸入、送出後備註有帶上

## 功能
- [ ] 店家電話 `tel:` 連結點下去跳出撥號確認
- [ ] 選好名字、送出訂單，出現成功 toast 與「已於 HH:mm 送出」
- [ ] 關掉分頁/退出 LINE 再開同一連結：自動記住上次選的名字並帶出已送出的訂單（localStorage）
- [ ] 已訂過的人被他人點選時，會出現「你確定是本人嗎？」確認
- [ ] 更新、取消訂單流程可用；團已關閉/截止時整頁唯讀並顯示「已關閉」或「已截止」
- [ ] 修改數量／品項備註／訂單備註時顯示「有尚未送出的修改」與「儲存修改」；改回原值恢復「訂單已送出」且不可重送
- [ ] 準備裝置資訊及送出期間不能重複送出或修改餐點；失敗保留輸入，可重試
- [ ] 在長名單底部選擇已訂者，身分 Dialog 立即在畫面中央可見；「選錯了」、Escape、關閉、背景取消後回原姓名，確認後到訂餐區
- [ ] 截止／409 後只顯示重新查詢的已送出餐點、備註與快照金額，不顯示未送出草稿；查詢失敗可重試，且不誤認為沒有訂餐
- [ ] 接近截止時間儲存修改，舊訂單查詢較晚回應時仍以最後成立訂單為準；送出與重新驗證期間不顯示舊摘要
- [ ] 售完回應後遇到團單更新失敗，頁內顯示重試，原數量／品項備註／訂單備註不消失；重試成功仍保留選餐
- [ ] 已載入團單後分享連結失效（404）／無權限（403），明確顯示失效／無權限且不再呈現訂餐、儲存及取消操作；不得誤顯示「保留目前選餐」
- [ ] 管理頁長品名、大金額與售完控制在窄螢幕不重疊；總份數／金額與繳費摘要在清單上方
- [ ] 收單中分享在上方；截止／關閉／封存後「分享與訂購連結」折疊在主要內容之後，切換階段不改目前 tab
- [ ] 開團第三步可核對名單／人數、店家、資料來源及歸屬；修改選擇後保留標題、地址、截止時間與備註
